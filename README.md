# Web Development Project 6 - Pokemon Data Dashboard

Submitted by: Lloani Mendez

This web app: Has a data dashboard of 20 pokemons with their information of id, name, height, weight, and base experience. Gathered from the pokemon API. You can filter the content displayed on the dashboard with the search bar for the name, dropdown for the type of pokemon, and range number inputs for a minimun or maximum experience. There are three summary information of the data displayed such as total pokemons displayed, average base experience, and the most common type of pokemon. As well as two charts where the first chart shows the amount of pokémons of each type and the second chart compares the height vs. weight of the 20 pokémons. You can also click on one of the pokémons on the dashboard to learn more about them. There you will see extra information such as moves and basic experience stats in the fields of hp, attack, defense, special-attack, special defense, and speed. An about page was also added to give a basic walkthrough of what this website is. 

Time spent: 8 hours spent in total
